# QuizApp

Mobile quiz application created in React Native as a practice project for learning mobile app development.
The app allows users to answer quiz questions, navigate between screens, and view their final score after completing the quiz.

## Features

* multiple choice questions
* score tracking
* simple interface
* navigation between screens

## Technologies

* React Native
* JavaScript
* Expo
